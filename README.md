 Portfolio Website - Semantic HTML & Accessibility

A multi-page personal portfolio website built using pure HTML5 and CSS3, adhering strictly to modern semantic standards and WCAG accessibility guidelines.

🚀 Features

- Semantic HTML5 Elements:* Structured using `<header>`, `<nav>`, `<main>`, `<article>`, `<section>`, and `<footer>` for clear document hierarchy.
- Accessibility & SEO: Implemented ARIA roles/labels, explicit form labeling, and SEO-friendly meta tags to achieve optimal Lighthouse scores.
- Multi-page Layout: Includes Home, About, Projects, and an accessible Contact form.
- Projects Highlighted: Showcases key projects including PostrIQ (AI-powered poster critique platform), Symposium Registration Platform, and a Python Movie Recommendation Engine[cite: 1].

 🛠️ Tech Stack

- Markup & Styling: HTML5, CSS3
- Tools: Git, GitHub, Visual Studio Code

 📁 File Structure

- `index.html` - Home page overview
- `about.html` - Education, skills, and internship background
- `projects.html` - Detailed showcase of development and AI projects
- `contact.html` - Accessible contact form with proper label associations
- `style.css` - Clean, responsive styling across all pages
